# Youth Sports Coaching Plans

Home training plans for Greg's two boys (ages **7** and **5**): **baseball, soccer, flag football and general athleticism**, plus tips for coaching groups at the fields. Each week has a theme, five short sessions (20 to 30 minutes), and builds on the week before.

> **Kid page (GitHub Pages):** [grrhero.github.io/youth-sports-coaching](https://grrhero.github.io/youth-sports-coaching/) — calendar, drill cards, and videos for THE GOONIES. Coach markdown plans stay in this repo (see indexes below).
>
> Browse the plans on GitHub, or open the generated HTML under [`site/`](site/index.html) offline.

## How the week works

| Day | What |
|---|---|
| **Mon** | Session 1 |
| **Tue** | Session 2 |
| **Wed** | 10-minute play day (no new lesson, just play) |
| **Thu** | Session 3 |
| **Fri** | Session 4 |
| **Sat** | Session 5 |
| **Sun** | Rest |

Move days around as needed. Every week touches all four areas. Session 2 is always soccer; flag football is Session 4 in Weeks 1–2 and Session 3 in Week 3; Session 5 is always a mixed day (Backyard Olympics, Teach-Back Day, Mixed Backyard Day). The schedule table shows each session's sport.

## Adding a new week

Every week is a folder `weeks/week-NN/` with the same layout. Two ways to add one:

**A. From a full plan written as one Markdown file** (any of the layouts in `sources/`: `## Session N — …`, `## SESSION N: …` or `## N. Session N: …`):

```bash
cp ~/week4_plan.md sources/week-04-plan.md
python3 scripts/import_plan.py 4 sources/week-04-plan.md --week-of "Oct 26, 2026"   # splits into weeks/week-04/
# edit weeks/week-04/week.json: set the sport for each session (and per activity if a session mixes sports)
python3 scripts/build.py                                   # refreshes indexes, schedule, site/, data/plan.json
git add -A && git commit -m "Add week 4" && git push
```

The importer sends `## Session …` sections to `session-N.md`, the group/volunteer-coaching section to `group-coaching.md`, and everything else to the week `README.md`, copying the text as-is.

**B. By hand:** `python3 scripts/new_week.py 4` creates `weeks/week-04/` with a README and five session files copied from the template. Fill them in, then run `python3 scripts/build.py`.

What the indexes pick up from a session file:
- title `# Week N · Session N: <Title> (NN min)`; the sport comes from `week.json` (or a `<Sport>: ` prefix in the title)
- activity headings `## Warm-up | Skill 1 | Skill work[, 7yo] | Skill Work A | Game | Finale | Cool-down: <Name> (time)`, or a numbered `1. **Station:** …` list for station days
- cue words from `· Cue: **Word**` in the heading or a `**Cue:**` / `**Cue words:**` line
- every YouTube link (session, group-coaching or README); `week.json` `video_locations` attaches README-only videos to a session

## Viewing offline

`site/` holds a plain HTML copy of every page with working links. Clone the repo and double-click `index.html`. After changing anything, `python3 scripts/build.py` regenerates it (needs `pip install markdown`).
