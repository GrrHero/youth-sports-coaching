Youth Sports Coaching Plans

Home training plans for Greg's two boys (ages 7 and 5): baseball, soccer, flag football and general athleticism, plus tips for coaching groups at the fields. Each week has a theme, five short sessions (20 to 30 minutes), and builds on the week before.

Private repo. Browse it right here on GitHub (all pages are Markdown), or open index.html locally for a plain HTML copy (see Viewing offline).

How the week works

Day What
Mon Session 1
Tue Session 2
Wed 10-minute play day (no new lesson, just play)
Thu Session 3
Fri Session 4
Sat Session 5
Sun Rest

Move days around as needed. In the plans so far, sessions follow the same sport order: S1 baseball, S2 soccer, S3 flag football, S4 athleticism, S5 mixed backyard day.

Indexes

  • Cue words: every cue word, by sport, linked to its session
  • Videos: every YouTube link with title, channel and week/session
  • Drills & games: catalog by sport and activity type
  • Coaching principles: the general how-to-teach habits
  • Field coaching: all group-coaching topics across weeks
  • Progress log: fill in by date (session done, notes per boy)
  • Session template: for writing future weeks

Adding a new week

Every week is a folder weeks/week-NN/ with the same layout. Two ways to add one:

A. From a full plan written as one Markdown file (same section layout as sources/week-03-plan.md):

bash cp ~/week4_plan.md sources/week-04-plan.md python3 scripts/import_plan.py 4 sources/week-04-plan.md # splits into weeks/week-04/ python3 scripts/build.py # refreshes indexes, schedule, site/ git add -A && git commit -m "Add week 4" && git push

B. By hand: python3 scripts/new_week.py 4 creates weeks/week-04/ with a README and five session files copied from the template. Fill them in, then run python3 scripts/build.py.

To be picked up by the indexes, session files must keep the template's headings: # Week N · Session N: <Sport>: <Title> (NN min), activity headings like ## Warm-up: <Name> (5 min) · Cue: **Word**, and video lines starting 🎥 **Video:**.

Viewing offline

site/ holds a plain HTML copy of every page with working links. Clone the repo and double-click index.html. After changing anything, python3 scripts/build.py regenerates it (needs pip install markdown).
